# Security policy

## Reporting a vulnerability

Please don't open a public issue for a security problem. Report it privately through GitHub: [Report a vulnerability](https://github.com/javimentallab/Storyteller-Mobile/security/advisories/new).

Say what you found, how to reproduce it and which version you used. English or Spanish are both fine.

This project has a single maintainer, so replies are best effort. I aim to answer within 14 days.

## What counts

Anything where a book, a document or a service's answer can run code or reach files outside the app's folder, anything that leaks an access key, and anything that sends text or audio anywhere other than the service the user chose.

## Supported versions

Only the latest release gets security fixes.
