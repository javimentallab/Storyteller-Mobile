<p>Storyteller Mobile 把 EPUB 变成由神经语音朗读的有声书，并在播放时显示跟随音频的字幕。它还能导入有声书并转录以生成这些字幕，也能翻译书籍和文档。</p>
<p>手机上不运行任何模型，所以应用占用空间很小。每项工作都由你选择服务：使用你的访问密钥的公共服务，或你网络中自己的服务。任何具有类似 OpenAI API 的服务都可以，翻译还可以用 Ollama 和 llama.cpp。不包含任何服务：你需要自己的服务，或公共服务的账户，后者可能按用量收费。</p>
<ul>
<li><b>朗读</b>：用你选择的语言和语音朗读 EPUB。可从中断处继续，也可以边朗读边收听。可选的检查功能会重做听起来不对的句子，每种语言都有发音词典。</li>
<li><b>导入</b>：有声书会被复制到手机并分段转录，以生成同步字幕。</li>
<li><b>翻译</b>：EPUB、PDF、Word、PowerPoint、Excel、字幕和文本。PDF 会输出为翻译后的 EPUB，不保留版式。</li>
<li><b>收听</b>：支持章节、跳转到任意位置和后台播放。</li>
</ul>
<p>你的文本和音频只会发送到你选择的服务，服务的运营者可以看到你发送的内容。访问密钥加密保存在手机上。没有账户、广告或分析。</p>
<p>提供英语、西班牙语、葡萄牙语、法语、德语、意大利语、荷兰语、波兰语、俄语、乌克兰语、中文、日语、韩语、泰语和印地语版本。</p>
