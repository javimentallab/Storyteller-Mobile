<p>Storyteller Mobile เปลี่ยน EPUB เป็นหนังสือเสียงที่อ่านด้วยเสียงนิวรัล และเล่นพร้อมคำบรรยายที่ตามเสียง นอกจากนี้ยังนำเข้าหนังสือเสียงและถอดเสียงเพื่อสร้างคำบรรยายเหล่านั้น รวมถึงแปลหนังสือและเอกสาร</p>
<p>ไม่มีโมเดลทำงานบนโทรศัพท์ แอปจึงมีขนาดเล็ก แต่ละงานคุณเลือกบริการได้เอง จะเป็นบริการสาธารณะที่ใช้คีย์การเข้าถึงของคุณ หรือบริการของคุณเองในเครือข่ายก็ได้ ใช้ได้ทุกบริการที่มี API แบบ OpenAI และใช้ Ollama กับ llama.cpp สำหรับการแปลได้ด้วย ไม่มีบริการรวมอยู่ในแอป คุณต้องมีบริการของตัวเองหรือบัญชีของบริการสาธารณะ ซึ่งอาจคิดเงินตามการใช้งาน</p>
<ul>
<li><b>อ่าน</b>: EPUB ในภาษาและเสียงที่คุณเลือก ทำต่อจากจุดที่หยุดได้ และฟังระหว่างที่อ่านได้ มีการตรวจแบบเลือกได้ที่ทำประโยคซึ่งฟังผิดใหม่ และมีพจนานุกรมการออกเสียงสำหรับแต่ละภาษา</li>
<li><b>นำเข้า</b>: หนังสือเสียงจะถูกคัดลอกไปยังโทรศัพท์และถอดเสียงเป็นช่วง ๆ เพื่อสร้างคำบรรยายที่ตรงจังหวะ</li>
<li><b>แปล</b>: EPUB, PDF, Word, PowerPoint, Excel, คำบรรยาย และข้อความ PDF จะออกมาเป็น EPUB ที่แปลแล้วโดยไม่มีเลย์เอาต์เดิม</li>
<li><b>ฟัง</b>: มีบท ข้ามไปยังตำแหน่งใดก็ได้ และเล่นในพื้นหลัง</li>
</ul>
<p>ข้อความและเสียงของคุณจะส่งไปยังบริการที่คุณเลือกเท่านั้น และผู้ดูแลบริการเห็นสิ่งที่คุณส่งได้ คีย์การเข้าถึงถูกเก็บแบบเข้ารหัสไว้ในโทรศัพท์ ไม่มีบัญชี โฆษณา หรือการวิเคราะห์</p>
<p>รองรับภาษาไทย อังกฤษ สเปน คาตาลัน กาลิเซีย บาสก์ โปรตุเกส ฝรั่งเศส เยอรมัน อิตาลี ดัตช์ โปแลนด์ รัสเซีย ยูเครน จีน ญี่ปุ่น เกาหลี และฮินดี</p>
