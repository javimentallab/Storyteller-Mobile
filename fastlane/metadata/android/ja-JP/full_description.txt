<p>Storyteller Mobile は EPUB をニューラル音声で朗読したオーディオブックに変え、音声に合わせて動く字幕付きで再生します。オーディオブックを取り込んで文字起こしし、その字幕を作ることもでき、本やドキュメントの翻訳もできます。</p>
<p>スマートフォン上ではモデルを動かさないので、アプリは軽いままです。作業ごとにサービスを選べます。アクセスキーを使う公開サービスでも、ご自身のネットワーク上のサービスでもかまいません。OpenAI のような API があれば使え、翻訳には Ollama や llama.cpp も使えます。サービスは含まれていません。ご自身のサービスか、公開サービスのアカウントが必要です。公開サービスは従量課金の場合があります。</p>
<ul>
<li><b>朗読</b>：選んだ言語と音声で EPUB を読み上げます。止まったところから再開でき、朗読中に聴くこともできます。おかしく聞こえる文をやり直す確認機能（任意）と、言語ごとの発音辞書があります。</li>
<li><b>インポート</b>：オーディオブックをスマートフォンにコピーし、分割して文字起こしして同期字幕を作ります。</li>
<li><b>翻訳</b>：EPUB、PDF、Word、PowerPoint、Excel、字幕、テキストに対応。PDF はレイアウトなしの翻訳済み EPUB になります。</li>
<li><b>再生</b>：章の移動、任意の位置へのジャンプ、バックグラウンド再生ができます。</li>
</ul>
<p>テキストと音声は選んだサービスにだけ送られ、その運営者は送られた内容を見ることができます。アクセスキーはスマートフォンに暗号化して保存されます。アカウント、広告、分析はありません。</p>
<p>日本語、英語、スペイン語、カタルーニャ語、ガリシア語、バスク語、ポルトガル語、フランス語、ドイツ語、イタリア語、オランダ語、ポーランド語、ロシア語、ウクライナ語、中国語、韓国語、タイ語、ヒンディー語に対応。</p>
